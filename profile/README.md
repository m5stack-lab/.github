**m5stack-lab** is where [ry-ops](https://github.com/ry-ops) builds ESP32 firmware and tools for M5Stack hardware: the Cardputer ADV, the Tab5, the StickS3 and the PaperColor e-paper board.

> [!NOTE]
> This is an unofficial, personal project space. It is **not affiliated with M5Stack**.

## Projects

| Project | Device | What it does |
|---|---|---|
| [cardputer-adv-mirror](https://github.com/m5stack-lab/cardputer-adv-mirror) | Cardputer ADV | Mirrors the display in any browser over WiFi (GRAM readback over SPI, WebSocket streaming) |
| [tab5-mirror](https://github.com/m5stack-lab/tab5-mirror) | Tab5 | The same browser mirror for the Tab5, plus remote control |
| [Liner](https://github.com/m5stack-lab/Liner) | PaperColor | A now-playing "liner notes" display for Volumio on color e-paper |
| [doomagotchi](https://github.com/m5stack-lab/doomagotchi) | Tab5 + Cardputer ADV | Self-playing DOOM where live 2.4 GHz RF becomes the demons, linked over LoRa |

A few more works in progress live in private repos until they're ready.
